# Ryu - Tip Calculator (Flutter)

## Run
1. Put this folder anywhere and open a terminal inside it.
2. Generate platform folders (android/ios/web): `flutter create .`
3. Get packages: `flutter pub get`
4. Run: `flutter run`

## Structure
- lib/main.dart                         App entry point and theme
- lib/screens/tip_calculator_screen.dart Main UI (input, slider, split)
- lib/widgets/result_card.dart          Result display card
- lib/utils/tip_logic.dart              Calculation logic
